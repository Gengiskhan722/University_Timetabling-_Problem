# University_Timetabling-_Problem
Proyecto para el proceso de admisión a la maestria en sistemas distribuidos.
La solución general se encuentra desarrolada en el archivo final.py,
los archivos posteriores son implementaciones segmentadas que se utilizaron durante el proceso de desarrollo y para realizar cálculos.
Para ejecutar el proyecto solo es necesario descargar el archivo final y tener instalado Python con las librerias basicas.
Sre recomienda ejecutar en el sistema operativo Linux.
